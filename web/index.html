    Reading Certificate Transparency

    Logs contain historical certificate and precertificate entries. A logged name may be stale, a wildcard, or a name that never had a publicly reachable service. A date window alone says nothing about revocation or current deployment.

    Live lookups use the community-operated crt.sh service. Its JSON interface is undocumented and can be slow. Narrow large searches or use the source link if a search fails. See RFC 9162 for CT background.
